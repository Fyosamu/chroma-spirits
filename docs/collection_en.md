# Chroma Spirits — Collection Description (for OpenSea)

## Short description

> 100 one-of-one beings made of pure color, born where the spectrum breaks.

## Long description

Chroma Spirits is a collection of 100 unique generative characters. Each spirit is
assembled from 9 trait categories that combine into a single identity that can
never be repeated:

- **12 Palettes** — from everyday Sunset and Ocean tones to the fabled **Gold** and **Void** spirits, which appear in fewer than 3% of the collection
- **6 Backgrounds** — Plain, Stripes, Dots, Rays, Grid, Bokeh
- **10 Eye styles** — including Laser, Star and Heart
- **9 Mouths** — from Cat to Fang
- **10 Headwear pieces** — Crown, Halo, Top Hat, Horns, Headphones and more
- **8 Eyewear items** — Diamond Shades and Heart Glasses among the rarest
- **7 Collar accessories** — Chain, Medal, Scarf, Bow Tie…
- **5 Ear types** — Cat, Bunny, Bear, Robot
- **4 Aura tiers** — Spark, Cosmic, Divine (Divine is Legendary)

### Rarity, made transparent

Every trait ships with its exact probability in the on-chain metadata, and every
token carries a verified rarity rank. Nothing is hidden: check `rarity_rank` and
`probability` fields on any item.

### Rarities

| Tier | Meaning |
